OBSERVATIONS — Required Agent Protocol

You MUST record observations about the codebase as part of your task.
Your task is NOT complete until you have recorded at least one observation.

COMMAND TEMPLATE (copy and adapt):

    pudl observe "description of what you found" \
        --kind <kind> --scope <repo>:<path>

REQUIRED FLAGS:

    --kind    One of the values listed below. No others.
    --scope   Format: repo_name:path (e.g. myapp:pkg/auth). See "nous guide scope".

VALID --kind VALUES (use ONLY these):

    obstacle      Something blocking progress or causing pain
    bug           A defect — incorrect behavior, race condition, crash
    suggestion    An improvement opportunity — refactor, split, simplify
    pattern       A recurring structure worth noting — not good or bad
    antipattern   A recurring structure that causes harm
    fact          A verified truth — test results, measurements, counts
    opportunity   An unrealized possibility — new feature, integration, optimization

RULES:

    1. One observation per concern. Never combine multiple issues.
    2. Be specific and concrete. Name files, packages, functions.
    3. Always include --scope with repo:path format.
    4. Always include --kind from the list above.
    5. Use --source <your-agent-name> if you have an agent identity.
    6. Record what you actually found, not what you expected to find.
    7. Record obstacles and bugs even if you fixed them — the observation
       is about what existed, not what exists after your changes.

DO NOT:

    - Combine multiple concerns in one observation
    - Use vague descriptions ("code could be better")
    - Omit --kind or --scope
    - Invent kind values not in the list above
    - Editorialize — state facts, not opinions about facts
    - Skip observations because "it's minor" — minor things accumulate

EXAMPLES:

    pudl observe "auth.go has circular import with user package" \
        --kind obstacle --scope myapp:pkg/auth

    pudl observe "TestCache_Invalidation has race condition under -count=100" \
        --kind bug --scope myapp:internal/cache

    pudl observe "all handlers follow middleware chain pattern consistently" \
        --kind pattern --scope myapp:cmd/api

    pudl observe "config.Config struct has 43 fields across 6 concerns" \
        --kind suggestion --scope myapp:internal/config

    pudl observe "no integration tests exist for the billing API" \
        --kind obstacle --scope myapp:cmd/api

BEFORE COMPLETING YOUR TASK, VERIFY:

    [ ] You recorded at least one observation
    [ ] Every observation has --kind and --scope
    [ ] --scope uses repo:path format
    [ ] --kind is from the valid list above
    [ ] Each observation covers exactly one concern
    [ ] Descriptions are specific (name files, packages, functions)
